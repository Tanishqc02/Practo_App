# Practo – Doctor Consultation & Lab Tests (Flutter)

Run: `flutter pub get && flutter run -d chrome` (or `-d macos` / an emulator).

Screens: Home · Doctor search (specialty/location/availability/rating/type filters) · Doctor profile with slot calendar ·
Booking · Video consult (simulated HD call + chat) · Text chat · Prescription viewer · Lab tests with home collection tracking ·
Lab report viewer with range bars · Medicines with Rx upload, cart, 5% refill subscription · Health vault · Vitals charts (BP/sugar/weight) ·
Pill reminders with pill images · Practo Plus (₹999/yr).

Pricing: GP ₹299 · Specialist ₹499 · Top ₹799 · Full body checkup from ₹999 · Plus ₹999/yr · Refill 5% off.
All data is mock and in-memory (see lib/data.dart); payments and video are simulated.
